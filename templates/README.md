# Templates

Reusable reporter-mode templates for `.spark-flow` tasks, issue trackers, and
agent handoffs.

| Template | Use |
|----------|-----|
| `BRIEF.md` | Task goal, repo, branch, and owner model. |
| `REPORT.md` | Generic agent or human report. |
| `HANDOFF.md` | Agent-to-agent or specialist handoff. |
| `APPROVAL.md` | Human approval or rejection record. |
| `DECISION.md` | Durable decision note. |
| `CLOSEOUT.md` | Final task summary and follow-ups. |
| `PROJECT_PHASE.md` | Project phase (Prototype/Alpha/Beta/MVP) and exit criteria. |
| `PROJECT_OPERATING_PLAN.md` | Portfolio plan: intent, workflow, pattern, research/engineering gates, backlog (`liaison plan-project --write`). |
| `BUILD_TRACE.md` | Per-slice log of how agents built code (`liaison record-build`). |
| `AGENT_RECIPE.md` | Export template for custom agents (`liaison export-agent-recipe --write`). |
| `DEBRIEF_ACK.md` | Operator acknowledgment of debrief options. |
| `CURRENT_STATE_UPDATE.md` | Structured liaison memory refresh. |
| `example.task.prompt.md` | Legacy task phase prompt example. |

## Closed feedback templates

| Template | Use |
|----------|-----|
| `OBJECTIVES.md` | Success criteria and alignment constraints. |
| `OBSERVATIONS.md` | Observations from agents, tools, tests, and users. |
| `EVALUATIONS.md` | Rubric-based assessments. |
| `LEARNINGS.md` | Lessons that update future behavior. |
| `IMPROVEMENTS.md` | Concrete system or process improvements. |
| `FEEDBACK_LOOP.md` | Compiled loop review. |
