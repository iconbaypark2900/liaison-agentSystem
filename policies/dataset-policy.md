# Dataset Policy

## Purpose

Control how datasets are discovered, profiled, used, and published.

## Required metadata

Every dataset candidate must record:

- source
- license
- intended use
- fields/schema
- splits
- size
- known risks
- PII/sensitive data assessment
- train/test leakage risk

## Rules

- Private data must not be uploaded externally without approval.
- Dataset cards must be reviewed before publishing.
- ML-Intern may inspect and profile datasets, but human approval is required before promotion.
